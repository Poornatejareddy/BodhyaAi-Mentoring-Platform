# Support Guide

If you need help or have questions about using or developing BodhyaAI, please use the following resources:

## 📚 Documentation
Before opening an issue or asking for support, please review the project documentation:
*   [Root README.md](./README.md) - Project setup, installation, and deployment.
*   [AI Services README.md](./ai-services/README.md) - Details on microservice design and execution.
*   [Audit and Cleanup Report](./CLEANUP_REPORT.md) - Understanding recent project refactorings.

## 💬 Community Channels
*   **GitHub Issues**: For reporting bugs, proposing features, or submitting feedback.
*   **Discussions**: For general questions, ideas sharing, and developer discussions.

## 🛠️ Filing a Bug Report
If you find a bug:
1. Check the existing issues to see if it has already been reported.
2. If not, open a new issue using our [Bug Report Template](.github/ISSUE_TEMPLATE/bug_report.md).
3. Provide as much detail as possible, including logs, screenshots, and reproduction steps.
