# Learning guide

Estimated orientation: 8–12 hours for a developer; 2–4 hours for a product stakeholder.

1. Read `docs/README.md`, vision and architecture (45 minutes).
2. Follow a login/profile/mentor flow through frontend route → frontend service → backend route/controller/model (2 hours).
3. Read the risk and cognitive services plus the data/constraints documents (2 hours).
4. Trace alerts, intervention and Socket.IO workflows (1 hour).
5. Read production/SaaS/integration roadmap before changing architecture (1 hour).

For beginners: React renders pages and calls API services; Express authenticates and coordinates domain logic; MongoDB persists documents; FastAPI services make model predictions; Gemini generates language output. A prediction is a decision-support signal, not a fact about a student.
