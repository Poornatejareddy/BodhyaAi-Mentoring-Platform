# BodhyaAI knowledge base

BodhyaAI is a role-based academic mentoring platform intended to surface academic risk earlier, explain contributing factors, and help mentors coordinate student support. It is currently a working prototype/research system, not an institution-ready SaaS product.

## Reading order

1. [Vision](vision/README.md) and [current status](project-status/README.md)
2. [Architecture](architecture/README.md), [data model](database/README.md), and [API inventory](api/README.md)
3. [AI services](ai/README.md), [dataset assumptions](data/README.md), and [constraints](constraints/README.md)
4. [Features](features/README.md) and [mentor workflow](workflows/README.md)
5. [Production readiness](production/README.md) and [SaaS roadmap](saas/README.md)

Status labels used throughout: **Implemented** means source code exists; **Partial** means a path exists but lacks operational safeguards; **Prototype** means it is useful for a demonstration but not validated for institutional decisions; **Recommended** is future work.
