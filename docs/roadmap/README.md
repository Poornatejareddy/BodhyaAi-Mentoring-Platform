# Roadmap

**1.0 – safe pilot:** one institution, SSO, verified SIS/LMS imports, data contracts, risk-policy review, mentor training, outcomes and audit dashboards.

**2.0 – operational platform:** multi-tenancy, department configuration, import workers, notification preferences, intervention SLAs, model registry/evaluation, mobile-responsive workflows.

**3.0 – ecosystem:** branded tenant portals, billing, parent/guardian policy layer, calendar/video integrations, research-safe analytics, native/mobile app if usage justifies it.

**5.0 – intelligence layer:** longitudinal causal evaluation, adaptive learning recommendations, knowledge graph and multi-agent assistance only after governance, evaluation, and human supervision are mature. Priority follows harm reduction and demonstrable mentor value, not model novelty.
