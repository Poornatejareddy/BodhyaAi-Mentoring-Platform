# Security Policy

## Supported Versions

Only the latest release of BodhyaAI is supported for security updates.

| Version | Supported |
| --- | --- |
| 1.0.x | :white_check_mark: |
| < 1.0.0 | :x: |

## Reporting a Vulnerability

We take the security of BodhyaAI very seriously. If you find a security vulnerability, please do NOT report it publicly via GitHub Issues. Instead, please report it directly via email to the security contact.

* **Email:** poornateja0079@gmail.com
* **Subject:** `[SECURITY VULNERABILITY] BodhyaAI Mentoring Platform`

Please include the following details in your report:
* A description of the vulnerability and its potential impact.
* Steps to reproduce the issue (including any proofs of concept, code snippets, or request payloads).
* Your contact information if you would like to receive updates on our progress.

We will acknowledge receipt of your report within 48 hours and work to provide a fix as quickly as possible.
