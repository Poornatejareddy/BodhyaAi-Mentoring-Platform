# Student digital profile

Implemented profile fields include identity (name, USN, department, section), SGPA/internal assessment maps, selected risk inputs, survey responses, embedded risk/personality outputs, mentor assignment, support engagement and consent flags.

Recommended additions: verified enrolment/course/term history; attendance provenance; assignments/projects/exam attempts; faculty observations with author/time; intervention and counselling records with separate sensitivity controls; goals, skills, certificates, extracurricular activity, career aspirations and placement outcomes. AI should use only fields with a defined purpose, data quality contract, consent/legal basis, documented feature rationale, and a human-review pathway.
