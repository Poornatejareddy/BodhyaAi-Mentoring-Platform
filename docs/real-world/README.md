# Real-world feature audit

**Production-ready:** none can be certified from source alone. The repository has working application flows but no deployment evidence, automated test suite, SLOs, security review, or model validation package.

**Needs improvement:** authentication, profiles, assignments, interventions, alerts, messaging, and administration. These map to legitimate institutional workflows but need tenant boundaries, lifecycle policy, reliability controls, and measurable outcomes.

**Prototype/experimental:** risk classifier, cognitive profile, SHAP explanations, RAG chat, AI intervention and class reports. Synthetic/training provenance and prospective evaluation are insufficient for high-impact education decisions.

**Redesign principle:** present AI as evidence for a trained human, never a verdict. Institutions need cohort policy, referral pathways, data minimization, escalation ownership, and intervention effectiveness metrics—not only risk labels.
