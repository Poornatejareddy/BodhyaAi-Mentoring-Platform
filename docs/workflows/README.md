# Mentor workflow

1. Mentor opens overview and reviews assigned mentees, alerts, unread messages and risk context.
2. Mentor verifies the underlying academic information before interpreting a risk label or explanation.
3. Mentor records an intervention (meeting, task, counselling, academic plan or follow-up), priority, deadline, notes and outcome.
4. Mentor contacts student through approved channel, sets a follow-up date, and observes progress over time.
5. Admin monitors assignment, alert, audit and operational metrics.

Current screens/routes support much of this sequence. Missing for real deployment: escalation policy, counsellor hand-off, SLA/reminder workflow, outcome measurement, supervisor review, safe-note boundaries, and case closure criteria.
