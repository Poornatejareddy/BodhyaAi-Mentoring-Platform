# AI and product constraints

Current prediction quality is constrained by manually entered inputs, no verified LMS/SIS/ERP/attendance feed, no longitudinal cohort history, no faculty observations, no validated intervention-outcome loop, and no documented real-data evaluation. Missing attendance, assessment, timetable, placement, counselling, or financial context can create false negatives and false positives.

The current architecture has no demonstrated multi-tenancy, institutional isolation, SSO, formal consent withdrawal propagation, model registry, data retention policy, backup/restore drill, observability, or incident response. These are launch blockers for an institutional SaaS deployment, not cosmetic improvements.
